# Product Requirements Document

## Product name
Repository Security Platform

## Problem
The team needs a central place to continuously monitor internal code repositories for security and quality risks without relying on fragmented scanner outputs.

## Primary users
- owner/admin
- security reviewer
- developer
- viewer

## MVP goals
- create organizations and projects
- connect repositories
- trigger manual scans
- schedule recurring scans
- review findings by severity/category/status
- inspect scan history
- export reports
- maintain audit logs
- support RBAC

## Core features
1. Repository onboarding
2. Scan orchestration
3. Findings dashboard
4. Scan history
5. Artifact storage
6. Audit trail
7. Notifications
8. Suppression workflow

## Non-goals for MVP
- MCP server
- SSO/SAML
- AI remediation
- PR annotations
- container registry integrations
- advanced policy engine
