# Locked Stack

## Application
- Frontend: Next.js
- Backend API: FastAPI
- Workers: Python background workers
- Database: Neon Postgres
- ORM: SQLAlchemy
- Auth: Neon Auth *(for now)*

## Infrastructure
- Frontend hosting: Vercel
- Backend hosting: Render
- Queue/cache: Upstash Redis
- Object storage: Cloudflare R2

## Scanner stack
### Core
- Trivy
- Gitleaks
- OSV-Scanner / OSV API
- Syft
- Grype

### Optional later
- Checkov
- Semgrep CE
