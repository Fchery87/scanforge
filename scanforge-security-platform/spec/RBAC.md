# RBAC

## Roles
- owner
- admin
- security_reviewer
- developer
- viewer

## Permissions summary
### owner
- full organization access
- manage integrations
- manage roles and settings

### admin
- manage projects and repositories
- trigger scans
- view findings and exports

### security_reviewer
- review findings
- suppress findings
- export reports

### developer
- view assigned projects
- trigger scans
- view findings and history

### viewer
- read-only access
